# Real-Time Digit Recognition Pipeline (OpenCV & TensorFlow)

Интерактивное Computer Vision приложение, объединяющее легковесную полносвязную нейронную сеть (МЛП) и движок захвата видеопотока высокой плотности в реальном времени. Система локализует область ввода (ROI) кадра веб-камеры, проводит векторную предобработку и выполняет потоковый инференс.

## 🏗 Архитектура и оптимизация пайплайна

* **Графовая оптимизация нормализации:** Одной из частых архитектурных ошибок является предобработка датасета на CPU циклами `for` до подачи в граф вычислений. В данном проекте масштабирование признаков (`feature scaling` из диапазона $[0, 255]$ в $[0, 1]$) интегрировано непосредственно в саму модель Keras в качестве декларативного слоя `Rescaling`. Это позволяет утилизировать вычислительные мощности GPU при пакетной обработке данных.
* **Векторизованный препроцессинг инференса:** Обработка видеопотока требует минимального пинга между кадрами (низкий `frame latency`). Локализованная матрица области интереса (ROI) подлежит цветовой конвертации (BGR-to-Gray), битовой инверсии (`cv2.bitwise_not`, так как полносвязная модель обучена на оригинальном распределении контрастности MNIST) и пространственному масштабированию с интерполяцией площади (`cv2.INTER_AREA`) без использования блокирующих процессор циклов.
* **Изолированный слой предсказания:** Применение методов `np.expand_dims` формирует корректные оси тензора (добавление размерности батча и канала цветности), что исключает необходимость перекомпиляции или пересоздания входных слоев модели во время выполнения приложения.

## 📦 Стек технологий

* **Deep Learning:** TensorFlow 2.x, Keras (Sequential API, Dense/Flatten/Rescaling layers).
* **Computer Vision:** OpenCV (Video capture, Image processing, ROI localization, UI rendering).
* **Математические вычисления:** NumPy (Манипуляция тензорами и осями массивов).

## 🚀 Инструкция по запуску

### Зависимости
Проект требует наличия веб-камеры и установленных библиотек обработки медиа-данных:
```bash
pip install tensorflow opencv-python numpy
```
### Выполнение

Скрипт автоматически проверит наличие скомпилированных весов модели в корневой папке. При их отсутствии приложение запустит фазу предварительного обучения на базе оригинального датасета MNIST, сохранит веса в .h5 контейнер и инициализирует интерактивный видеопоток:
```bash

python vision_app.py
```
### Интерфейс управления

*    Поместите лист бумаги с написанной от руки цифрой (или покажите экран смартфона) в зеленый квадрат в центре окна.

*    Для завершения работы приложения и освобождения ресурсов видеозахвата нажмите клавишу Q на клавиатуре в активном окне трансляции.
